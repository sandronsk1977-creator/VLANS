📖 Referência de Comandos

configure terminal - Entrar no modo de configuração
vlan <id> - Criar uma VLAN
name <nome> - Nomear a VLAN
exit - Sair do modo atual
interface <port> - Selecionar uma porta
switchport mode access - Definir como porta access
switchport access vlan <id> - Atribuir porta à VLAN
switchport mode trunk - Definir como porta trunk
show vlan brief - Ver resumo das VLANs
show interfaces status - Ver status das portas
copy running-config startup-config - Salvar configuração
